# Palette's Journal

## 2025-05-10 - HTML Image Alt Attributes vs Data-Alt Attributes
**Learning:** Using `data-alt` instead of `alt` on `<img>` elements renders images invisible/unannounced to screen readers. Standard `alt` attributes must always be used for accessible image descriptions.
**Action:** Replace non-standard `data-alt` attributes with proper `alt` attributes across static HTML templates.
